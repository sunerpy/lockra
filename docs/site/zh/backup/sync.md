# 多设备同步

本页介绍如何通过你自己的存储让多台设备保持同样的账号、新设备如何加入，以及 Lockra 如何让存储无法读取你的账号。

同步默认关闭，需要你自行开启。Lockra 不运行服务器，也不需要注册账户：你的设备通过你选择的 S3 兼容存储桶或 WebDAV 文件夹交换数据，写入的一切内容在离开设备之前都已加密。Lockra 从 0.4.0 版起提供同步。

## 准备工作

- **S3 兼容存储**：AWS S3、Cloudflare R2、Backblaze B2、阿里云 OSS、MinIO 或其他 S3 兼容服务中的一个存储桶，以及一个可以在其中列出、读取、写入和删除对象的访问密钥。或者 **WebDAV**：Nextcloud、坚果云、群晖 NAS 或其他 WebDAV 服务中的一个文件夹，以及用户名和密码（服务提供应用专用密码时，请使用应用专用密码）。
- 以 `https://` 开头的地址。Lockra 拒绝普通的 `http://` 地址，本机地址除外。

## 开始同步

1. 在第一台设备上，打开「设置 › 同步」，选择「开始同步」。
2. 选择「S3 兼容」或「WebDAV」并填写存储信息。S3 需要填写「服务地址」、「区域」（服务没有区域时填 `auto`）、「存储桶」、「访问密钥 ID」和「访问密钥」；MinIO 等自建服务请开启「路径式访问」。「文件夹（可选）」是 Lockra 在存储桶或 WebDAV 文件夹中存放文件的位置（默认为 `lockra`）。
3. 确认「这台设备的名称」，输入主密码，然后选择「开始同步」。
4. Lockra 会显示「同步密钥」：`LKS1-` 加 14 组、每组 4 个字符。请把它抄下来或存入密码管理器，并与主密码分开保管。在手边没有其他设备时添加设备，或在所有设备都丢失后恢复，都需要同步密钥和主密码两者。之后可以在「邀请其他设备」中再次查看。

存储凭据保存在加密的保险库中，不会再次显示；「设置 › 同步」只显示不含凭据的存储信息。

## 添加设备

在已开启同步的设备上，打开「设置 › 同步」，选择「邀请其他设备」并输入主密码。Lockra 会显示二维码和邀请码文本，两分钟后隐藏。邀请码包含存储凭据和同步密钥，只能在你自己的设备上使用。

在新设备上：

- **尚未创建保险库**：在欢迎页选择「加入同步…」，粘贴邀请码，输入设备名称和「同步空间的主密码」，然后选择「加入」。Lockra 会用这个主密码创建保险库，账号随即同步过来。
- **已有保险库**：打开「设置 › 同步 › 加入已有的同步」。保险库中的账号会加入同步空间，保险库保留自己的主密码。

没有其他设备时，选择「同步密钥」而不是「邀请码」，然后填写存储信息和同步密钥。

同步空间的主密码是创建同步空间那台设备的主密码；之后如果在同步空间中的任一设备上修改过主密码，则为最新的主密码。修改后的主密码会在下次同步时写入同步空间。

## 同步的时机

保险库解锁期间，设备会在解锁时、每次修改 3 秒后、每 5 分钟，以及你选择「立即同步」时进行同步。保险库锁定期间不会发送任何内容。状态行会显示「已同步」及时间，或上次失败的原因；下一次同步会自动重试。

同一个账号在两台设备上都被修改时，所有设备都以较晚的修改为准。删除会在所有设备上移除该账号，除非该账号在删除之后又被修改过。「最近使用」的顺序只保存在各自的设备上。

## 设备

「设备」列出同步空间中的每台设备，以及它上次写入的时间。要移除丢失或不再使用的设备，请选择它的移除按钮：它的数据会从存储中删除。仍在使用的设备会在下次同步时重新出现。「重命名」会修改其他设备看到的本机名称。

## 修改存储设置或关闭同步

「修改存储设置」可以更换访问密钥、密码或地址，需要输入主密码。同步空间必须已经位于新的位置：请先移动它所在的文件夹。

「在这台设备上关闭同步」会停止本机的同步。账号保留在本机；同步空间和其他设备不受影响。之后可以用邀请码或同步密钥重新加入。

## 存储能看到什么

- **只有加密的文件。** 账号、账号的密钥、设备名称和时间在写入之前，都已在设备上用 XChaCha20-Poly1305 加密。每台设备写入一个文件，文件大小按 4 KiB 的整数倍填充，因此无法从大小推断账号数量。文件名只能看出设备的数量。
- **需要两个秘密才能打开同步空间。** 加密这些文件的密钥本身由主密码（经 Argon2id 派生，64 MiB 内存、3 轮）和同步密钥共同加密。没有同步密钥，即使拿到存储中的全部内容并猜中主密码，也无法打开；有了同步密钥，每猜一次主密码仍需完整运行一次 Argon2id。
- **改动会被发现。** 被修改、从其他设备或同步空间移来，或被换回旧版本的文件都会被拒绝，「设置 › 同步」会指出是哪台设备。你的账号保持不变。
- **无法阻止删除。** 能写入存储的人可以删除同步空间。这会中断同步，但不会影响保险库：每台设备都保留自己的账号。
- **备份不包含同步信息。** 存储设置、凭据和同步密钥只保存在保险库文件中。备份不包含这些内容；从备份恢复的设备需要重新加入同步空间。

## 出现问题时

| 提示                                                     | 处理方法                                                                                     |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 存储服务拒绝访问，请检查访问密钥或密码                   | 检查访问密钥或密码，并确认它可以在存储桶或文件夹中列出、读取、写入和删除。                   |
| 无法连接存储服务                                         | 检查网络和地址。Lockra 会使用系统中设置的代理。                                              |
| 存储服务返回错误，请检查存储桶或文件夹是否存在           | 检查存储桶、区域和「路径式访问」。                                                           |
| 这个存储里没有该同步密钥对应的同步空间                   | 检查地址、存储桶和「文件夹（可选）」：它们必须与其他设备上的设置相同。                       |
| 主密码或同步密钥不正确                                   | 输入同步空间的主密码（见上文），并检查同步密钥。                                             |
| 只能通过 HTTPS 连接存储（本机地址除外）                  | 使用服务的 `https://` 地址。                                                                 |
| 某台设备的同步数据比之前读到的旧，已拒绝。存储可能被回滚 | 存储返回了这台设备较旧的文件。该设备会在下次修改时重新写入；如果提示一直存在，请移除该设备。 |
