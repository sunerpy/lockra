# 多设备同步

本页介绍如何通过你自己的存储或 Lockra 中继让多台设备保持同样的账号、新设备如何加入，以及 Lockra 如何让存储无法读取你的账号。

<StatusTag status="available" /> 同步自 0.4.0 版起提供。

同步默认关闭，需要你自行开启，也不需要注册账户：你的设备通过 Lockra 中继、你选择的 S3 兼容存储桶或 WebDAV 文件夹交换数据，在电脑上也可以通过网盘客户端同步的文件夹交换，写入的一切内容在离开设备之前都已加密。

## 准备工作

- **S3 兼容存储**：AWS S3、Cloudflare R2、Backblaze B2、阿里云 OSS、MinIO 或其他 S3 兼容服务中的一个存储桶，以及一个可以在其中列出、读取、写入和删除对象的访问密钥。或者 **WebDAV**：Nextcloud、坚果云、群晖 NAS 或其他 WebDAV 服务中的一个文件夹，以及用户名和密码（服务提供应用专用密码时，请使用应用专用密码）。
- 以 `https://` 开头的地址。Lockra 拒绝普通的 `http://` 地址，本机地址除外。
- 或者在电脑上使用由网盘客户端同步的一个文件夹，不需要任何凭据（见下文[用网盘文件夹同步](#用网盘文件夹同步)）。
- 或者无需准备任何存储：使用 Lockra 内置中继或自建中继（见下文[经 Lockra 中继同步](#经-lockra-中继同步)）。

### 按服务商填写

<StatusTag status="available" /> 自 0.7.3 版起提供。

选择存储类型后再选择服务商，Lockra 会填好地址和访问方式，除凭据外只需填写下表中的项目。列表里没有的服务，请选择「其他 S3 兼容服务」或「其他 WebDAV 服务」，按下文填写全部字段。

| 服务商             | 需要填写                                           | 说明                                                                                             |

| AWS S3（全球区域） | 区域、存储桶、访问密钥                             | 北京或宁夏请选「AWS S3（中国区域）」：中国区域与全球区域的账号和密钥不通用。                     |
| AWS S3（中国区域） | `cn-north-1` 或 `cn-northwest-1`、存储桶、访问密钥 | 地址以 `.amazonaws.com.cn` 结尾。                                                                |
| Cloudflare R2      | 账户 ID、存储桶、访问密钥                          | 区域为 `auto`。                                                                                  |
| 阿里云 OSS         | 地域 ID（如 `cn-hangzhou`）、存储桶、AccessKey     | 2025 年 3 月 20 日之后开通的账号，不能用默认地址访问中国内地地域的存储桶，可改用中国香港等地域。 |

| 坚果云             | 账号、应用密码                                     | 应用密码在坚果云网页「账户信息 › 安全选项 › 第三方应用管理」中生成。                             |
| Nextcloud          | 服务器地址、用户名、应用密码                       | 应用密码在「设置 › 安全」中创建。                                                                |

## 开始同步

1. 在第一台设备上，打开「设置 › 同步」，选择「开始同步」。
2. 选择「S3 兼容」或「WebDAV」并填写存储信息。S3 需要填写「服务地址」、「区域」（服务没有区域时填 `auto`）、「存储桶」、「访问密钥 ID」和「访问密钥」；MinIO 等自建服务请开启「路径式访问」。「文件夹（可选）」是 Lockra 在存储桶或 WebDAV 文件夹中存放文件的位置（默认为 `lockra`）。
3. 确认「这台设备的名称」，输入主密码，然后选择「开始同步」。
4. 「设置 › 同步」会提醒你保存「恢复密钥」：`LKS1-` 加 14 组、每组 4 个字符。选择「显示恢复密钥…」并输入主密码，把它抄下来或存入密码管理器（与主密码分开保管），或选择「保存到文件…」，然后选择「我已记下」。只有所有设备都丢失、需要用存储设置和任一设备的主密码恢复同步空间时，才需要它。

存储凭据保存在加密的保险库中，不会再次显示；「设置 › 同步」只显示不含凭据的存储信息。

## 添加设备

在已开启同步的设备上，打开「设置 › 同步」，选择「邀请其他设备」并输入主密码。Lockra 会显示二维码，两分钟后隐藏。邀请码会把同步空间交给拿到它的设备，持有邀请码的设备无需其他密码即可加入，因此只能在你自己的设备上使用。

在新设备上扫描二维码，或粘贴配对链接（使用中继的同步空间，见下文[配对链接](#配对链接)）或邀请码（其他存储，见下文「无法扫码？」）：

- **尚未创建保险库**：在欢迎页选择「加入同步…」，输入设备名称，在「为这台设备设置主密码」中设置主密码并再输入一次，然后选择「加入」。Lockra 会用这个主密码创建保险库，账号随即同步过来。它可以与其他设备的主密码相同，也可以不同。
- **已有保险库**：打开「设置 › 同步 › 加入已有的同步」，输入「这台设备的主密码」。保险库中的账号会加入同步空间，保险库保留自己的主密码。

没有其他设备时，可以恢复同步空间：选择「恢复密钥」而不是「配对链接」，填写存储信息和恢复密钥，再输入同步空间中任一设备的主密码。如果这台设备的保险库使用其他主密码，Lockra 还会请你在「同步空间的主密码」中输入其中一台设备的主密码。

同步空间中的每台设备都保存一份同步空间的密钥，用这台设备自己的主密码和恢复密钥加密。因此，同步空间中任一设备的主密码加上恢复密钥，即可恢复同步空间。在某台设备上修改主密码后，新的主密码从这台设备的下次同步起可用于恢复。

### 更方便的邀请与加入

<StatusTag status="available" /> 自 0.7.3 版起提供。

- **用指纹或面容显示邀请码**：开启了 Touch ID、Windows Hello 或指纹解锁的设备，在「邀请其他设备」中可以用它代替主密码。
- **可以发送的邀请码**：在「无法扫码？」下选择「复制邀请码」，并会显示一个 10 位的口令。邀请码可以通过聊天或邮件发给新设备，口令请当面或电话告诉对方；新设备粘贴邀请码后输入口令即可加入。扫描二维码不需要口令。自 0.8.4 版起，使用中继的同步空间改用不需要口令的[配对链接](#配对链接)。
- **保存恢复密钥**：选择「保存到文件…」可以把恢复密钥保存到你选择的文件中。在保存或选择「我已记下」之前，「设置 › 同步」会一直提醒。

## 添加手机

<StatusTag status="available" /> 自 0.7.0 版起提供。

Android 应用的同步方式与电脑相同。先在同步空间中的一台设备上显示邀请码（「设置 › 同步 › 邀请其他设备」），再在手机上选择「设置 › 同步 › 加入已有的同步 › 扫码加入」，或在新安装的欢迎页选择「从同步加入」，然后扫描邀请码。邀请码由相机直接交给 Lockra，不会显示在手机上。也可以像在电脑上一样粘贴配对链接或邀请码，或用存储设置和恢复密钥恢复。

### 在手机上用指纹代替主密码

<StatusTag status="available" /> 自 0.8.6 版起提供。

在开启了「使用指纹解锁」的手机上，同步中需要主密码的地方都可以改用指纹验证：

- **邀请其他设备**和**显示恢复密钥…**：「默认解锁方式」为「指纹」时，页面打开后会自动请求指纹验证；取消后可以改为输入主密码。
- **加入已有的同步**：用扫码、配对链接或邀请码加入时，「这台设备的主密码」留空，选择「扫码加入」或「加入」后验证指纹。
- **修改存储设置**：主密码留空，选择「保存」后验证指纹。

用指纹加入后，这台手机在同步空间中的那份同步空间密钥暂时无法用它的主密码打开：下次用主密码解锁这台手机时，Lockra 会用主密码重新加密它，并在之后的同步中写入。在此之前，「设置 › 同步」会说明这一点；如果需要用恢复密钥恢复同步空间，请输入其他设备的主密码。用「恢复密钥」加入、在欢迎页加入并新建保险库，以及开始同步，仍需要输入主密码。

### 从手机添加电脑

<StatusTag status="available" /> 自 0.8.2 版起提供。

电脑无法扫码，因此同步空间建在手机上时，由手机以文本形式发送邀请。在手机上打开「设置 › 同步 › 邀请其他设备」：使用中继的同步空间，选择「复制配对链接」；其他存储，选择「无法扫码？」，再选择「复制邀请码」。配对链接或邀请码会放入剪贴板，不进入剪贴板历史，并在「设置 › 安全 › 清空剪贴板」设定的时间后清除。通过聊天或邮件把它发到电脑，在电脑的「加入已有的同步」（或欢迎页的「加入同步…」）中粘贴；邀请码还需要输入手机上显示的口令。

同一个同步空间中的设备地位相同：无论由哪台设备开始，所有修改都会双向同步。账号在手机上、电脑是新的时，也可以在电脑上开始同步并显示二维码，手机用自己的保险库加入，手机上的账号会并入同步空间并同步到电脑。

## 更简单的配对

<StatusTag status="available" /> 自 0.8.3 版起提供。

从这个版本起，添加设备时需要填写的内容更少：

- **只需要新设备自己的主密码。** 邀请码会把同步空间交给新设备，新设备不再需要输入其他设备的主密码。尚未创建保险库的设备在加入时设置自己的主密码并输入两次，可以与其他设备相同，也可以不同。
- **先显示二维码。** 「邀请其他设备」先显示二维码；可以发送的邀请码和口令放在「无法扫码？」下面，并提供「复制邀请码」。自 0.8.4 版起，使用中继的同步空间在二维码旁直接提供「复制配对链接」（见下文）。
- **恢复密钥。** 同步密钥改称恢复密钥，开始同步和邀请设备时都不再显示：在「设置 › 同步 › 显示恢复密钥…」中输入主密码后查看；在保存到文件或选择「我已记下」之前，Lockra 会一直提醒。只有所有设备都丢失、需要用存储设置和任一设备的主密码恢复同步空间时，才需要它。

邀请码会把同步空间交给拿到它的设备，持有邀请码的设备无需任何密码即可加入：只在你自己的设备上使用。0.8.2 及以前的版本无法读取这样的邀请码，这个版本也不接受旧版的邀请码：请先更新所有设备。

## 配对链接

<StatusTag status="available" /> 自 0.8.4 版起提供。

使用 Lockra 中继（内置中继或自建中继）的同步空间，添加设备只需要一条配对链接，不需要口令：

1. 在已开启同步的设备上，打开「设置 › 同步 › 邀请其他设备」，输入主密码，或用 Touch ID、Windows Hello、指纹验证。
2. 在新设备上扫描二维码；或者选择「复制配对链接」，通过聊天或邮件把它发到新设备。
3. 在新设备的「加入已有的同步」（或欢迎页的「加入同步…」）中粘贴配对链接，输入新设备自己的主密码，然后选择「加入」。

配对链接与二维码是同一份邀请：中继的地址和同步空间的密钥，不含任何存储凭据。它长期有效，拿到它的人无需任何密码就能加入同步空间、读取你的所有账号，直到你开始新的同步空间。请只把它发给你自己的设备。配对链接可能已被他人看到时（例如发到了其他人能看到的聊天中），请在所有设备上关闭同步，开始一个新的同步空间，再把设备加入其中。

安装了 0.8.3 的设备也可以粘贴配对链接加入。使用 S3 兼容存储、WebDAV 或网盘文件夹的同步空间不受影响：它们的邀请码包含存储凭据，可以发送的邀请码仍需口令。

## 用网盘文件夹同步

<StatusTag status="available" /> 自 0.7.4 版起提供。

在电脑上可以不填写任何存储凭据：选择一个由网盘客户端同步的文件夹，例如 OneDrive、iCloud 云盘、Dropbox、坚果云、Nextcloud、群晖 Drive 或 Syncthing 的文件夹。Lockra 只在其中写入加密的文件，由网盘客户端把它们传到其他设备。

1. 在网盘的同步文件夹中新建一个文件夹，例如 `Lockra`。
2. 在电脑上打开「设置 › 同步」，选择「开始同步」，存储类型选择「网盘文件夹」，再选择「选择文件夹…」并选中这个文件夹。
3. 确认「这台设备的名称」，输入主密码，然后选择「开始同步」。

这样的同步空间，邀请码不包含存储设置，也不包含这台电脑上的文件夹。新设备粘贴或扫描邀请码后，Lockra 会请你选择这台设备访问同一个文件夹的方式：

- **另一台电脑**：存储类型选择「网盘文件夹」，选中同一个网盘在这台电脑上的那个文件夹。
- **手机**：存储类型选择「WebDAV」，填写这个网盘的 WebDAV 地址，在「文件夹（可选）」中填写该文件夹在网盘中的路径，然后重新扫描邀请码。例如，坚果云客户端同步的 `我的坚果云/Lockra` 文件夹，对应的 WebDAV 地址是 `https://dav.jianguoyun.com/dav/`，文件夹是 `我的坚果云/Lockra`。

OneDrive、iCloud 云盘和 Dropbox 没有官方的 WebDAV，使用它们时只有电脑能加入。需要手机也同步时，请选用坚果云、Nextcloud 或群晖，或者改用 S3 兼容存储或 WebDAV。

读取本机的文件夹不需要联网：网盘客户端把其他设备的改动放进文件夹后，Lockra 约一秒后同步；此外，在前台时每 15 秒查看一次文件夹，切到其他窗口后以及同步失败后每分钟一次。其他设备的改动何时出现在这个文件夹中，取决于网盘客户端。网盘客户端未运行，或者文件夹被移动、删除时，「设置 › 同步」会提示找不到同步文件夹，Lockra 不会重新创建它；文件夹换了位置时，请在「修改存储设置」中重新选择。

0.7.3 及以前的版本不支持网盘文件夹：用这些版本打开同一个保险库文件时，账号照常可用，同步显示为关闭。

## 经 Lockra 中继同步

<StatusTag status="available" /> 自 0.8.1 版起提供。

中继是一台为同步空间保存加密文件的服务器，适用于没有自己存储的设备。Lockra 运行着一个内置中继，你也可以自己运行一个（[自建中继](/zh/backup/relay)）。对设备而言，中继只是另一种存储：设备写入的加密文件与写入其他存储时完全相同，中继无法打开其中任何一个。

1. 在第一台设备上，打开「设置 › 同步」，选择「开始同步」。「存储类型」默认为「Lockra 中继」，服务商为「Lockra 内置中继」，无需填写任何内容。使用自建中继时，请选择「自建中继」，并在「中继地址」中填写以 `https://` 开头的地址。
2. 确认「这台设备的名称」，输入主密码，然后选择「开始同步」。
3. 与使用其他存储时一样，保存「设置 › 同步」提醒你的恢复密钥。

这样的同步空间，邀请码（也就是配对链接）包含中继的地址和同步空间的密钥。添加手机时，在电脑上显示邀请码（「邀请其他设备」），再在手机上扫描二维码（「设置 › 同步 › 加入已有的同步 › 扫码加入」，或新安装时欢迎页上的「从同步加入」）：手机无需填写存储设置，只需输入主密码。也可以选择「复制配对链接」，在手机或电脑上粘贴，不需要口令（[配对链接](#配对链接)）。手边没有其他设备时，选择「恢复密钥」，保持「Lockra 中继」，再输入恢复密钥。

保险库解锁期间，设备会在中继上保持一个等待中的请求，其他设备写入时中继立即应答，改动约一秒后到达。此外，设备也按其他存储的间隔同步（[同步的时机](#同步的时机)）。

「修改存储设置」也可以把同步空间迁移到中继。与其他存储不同，中继上不必已有这个同步空间：这台设备会在下次同步时把它写入中继。之后请在其他设备上以同样方式修改存储设置。

中继能看到的内容：

- **与其他存储相同。** 加密的文件、按 4 KiB 取整的文件大小、同步空间中设备的数量和它们写入的时间，以及设备连接时使用的网络地址。中继看不到任何账号、密钥、设备名称、恢复密钥或主密码（[存储能看到什么](#存储能看到什么)）。
- **只有同步空间中的设备能修改它。** 设备用一个由恢复密钥计算得出的值证明自己的身份，从这个值无法推算出恢复密钥；中继只保存这个值的指纹，并拒绝所有不带这个值的请求。即使有人知道同步空间在中继上的位置，也无法读取或修改它。
- **中继可能无法访问。** 与任何存储一样，中继也可以删除同步空间：设备会保留所有账号，并在下次同步时重新写入。内置中继只有一台服务器；不希望同步空间依赖它时，请自建中继，或使用你自己的存储。

内置中继在设备最后一次访问同步空间 400 天后删除它，每个同步空间最多保存 64 台设备、32 MiB 数据，并限制每个网络地址的请求次数。中继已满时，同步会失败并提示「存储服务返回错误，请检查存储桶或文件夹是否存在」；中继要求设备放慢请求时，提示「无法连接存储服务」；下一次同步会自动重试。内置中继保存哪些内容，见[隐私](/zh/privacy#内置中继)页。

## 同步的时机

保险库解锁期间，设备会在解锁时、每次修改 3 秒后、每隔一段时间（见下文），以及你选择「立即同步」时进行同步。保险库锁定期间不会发送任何内容。状态行会显示「已同步」及时间，或上次失败的原因；下一次同步会自动重试。

### 更及时的同步

<StatusTag status="available" /> 自 0.7.3 版起提供。

- **在前台时更频繁**：Lockra 在前台时每分钟同步一次；在电脑上切到其他窗口后，每 5 分钟同步一次。在电脑上切回 Lockra 后，距上次同步满 30 秒就会同步。同步失败后，下一次在 5 分钟后进行，也可以选择「立即同步」。
- **看得到同步带来了什么**：同步新增、修改或删除了这台设备上的账号时，Lockra 会提示更改来自哪台设备，例如「已从 Pixel 8 同步：新增 2 个，修改 1 个」。

在多台设备上同时新增的账号都会保留，并出现在每台设备上。同一个账号在两台设备上都被修改时，所有设备都以较晚的修改为准。删除会在所有设备上移除该账号，除非该账号在删除之后又被修改过。同一个账号如果在两台设备上分别添加（例如两台设备都扫描了它的二维码），会出现两次：删除其中一个即可，删除也会同步。「最近使用」的顺序只保存在各自的设备上。

## 设备

「设备」列出同步空间中的每台设备，以及它上次写入的时间。要移除丢失或不再使用的设备，请选择它的移除按钮：它的数据和它保存的那份密钥会从存储中删除。仍在使用的设备会在下次同步时重新出现。「重命名」会修改其他设备看到的本机名称。

## 修改存储设置或关闭同步

「修改存储设置」可以更换访问密钥、密码或地址，需要输入主密码。同步空间必须已经位于新的位置：请先移动它所在的文件夹。

「在这台设备上关闭同步」会停止本机的同步。账号保留在本机；同步空间和其他设备不受影响。之后可以用邀请码或恢复密钥重新加入。

## 存储能看到什么

- **只有加密的文件。** 账号、账号的密钥、设备名称和时间在写入之前，都已在设备上用 XChaCha20-Poly1305 加密。每台设备写入一个文件，文件大小按 4 KiB 的整数倍填充，因此难以从大小准确推断账号数量。文件名只能看出设备的数量。
- **从存储打开同步空间需要两个秘密。** 在每台设备上，加密这些文件的密钥本身由这台设备的主密码（经 Argon2id 派生，64 MiB 内存、3 轮）和恢复密钥共同加密。没有恢复密钥，即使拿到存储中的全部内容并猜中某个主密码，也无法打开；有了恢复密钥，每猜一次主密码仍需完整运行一次 Argon2id。请为每台设备设置足够强的主密码。
- **邀请码本身就能打开同步空间。** 邀请码包含同步空间的密钥，拿到它的设备无需任何密码即可加入：Lockra 只在输入主密码（或通过 Touch ID、Windows Hello、指纹验证）后显示它，两分钟后隐藏，并在系统允许时阻止截屏。使用中继的同步空间，配对链接长期有效，无需口令即可加入，请只发给你自己的设备；其他存储可以发送的邀请码还需要口令。
- **设备之间不会互相覆盖。** 每台设备只写自己的文件，多台设备同时同步时会保留彼此的修改，S3 与 WebDAV 都是如此。
- **改动会被发现。** 被修改、从其他设备或同步空间移来，或被换回旧版本的文件都会被拒绝，「设置 › 同步」会指出是哪台设备。你的账号保持不变。
- **无法阻止删除。** 能写入存储的人可以删除同步空间。这会中断同步，但不会影响保险库：每台设备都保留自己的账号。
- **移除设备不会撤销其访问权限。** 被移除的设备仍保存着同步空间的密钥。要阻止丢失的设备、见过邀请码或配对链接的人，或知道恢复密钥和旧主密码的人访问同步空间，请在所有设备上关闭同步，开始一个新的同步空间，再把设备加入其中。
- **备份不包含同步信息。** 存储设置、凭据和恢复密钥只保存在保险库文件中。备份不包含这些内容；从备份恢复的设备需要重新加入同步空间。

## 出现问题时

| 提示                                                               | 处理方法                                                                                     |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 存储服务拒绝访问，请检查访问密钥或密码                             | 检查访问密钥或密码，并确认它可以在存储桶或文件夹中列出、读取、写入和删除。                   |
| 无法连接存储服务                                                   | 检查网络和地址。Lockra 会使用系统中设置的代理。                                              |
| 存储服务返回错误，请检查存储桶或文件夹是否存在                     | 检查存储桶、区域和「路径式访问」。                                                           |
| 这个存储里没有这个同步空间                                         | 检查地址、存储桶和「文件夹（可选）」：它们必须与其他设备上的设置相同。                       |
| 主密码或恢复密钥不正确                                             | 输入同步空间中任一设备的主密码（见上文），并检查恢复密钥。                                   |
| 这份邀请来自旧版本的 Lockra，请先把显示邀请的设备更新到最新版本    | 在显示邀请码的设备上更新 Lockra，然后重新显示邀请码。                                        |
| 只能通过 HTTPS 连接存储（本机地址除外）                            | 使用服务的 `https://` 地址。                                                                 |
| 某台设备的同步数据比之前读到的旧，已拒绝。存储可能被回滚           | 存储返回了这台设备较旧的文件。该设备会在下次修改时重新写入；如果提示一直存在，请移除该设备。 |
| 找不到同步文件夹：网盘客户端可能没有运行，或者文件夹已被移动或删除 | 启动网盘客户端，并确认文件夹仍在原处；文件夹换了位置时，请在「修改存储设置」中重新选择。     |
