# 多设备同步

本页介绍如何通过你自己的存储让多台设备保持同样的账号、新设备如何加入，以及 Lockra 如何让存储无法读取你的账号。

<StatusTag status="available" /> 同步自 0.4.0 版起提供。

同步默认关闭，需要你自行开启。Lockra 不运行服务器，也不需要注册账户：你的设备通过你选择的 S3 兼容存储桶或 WebDAV 文件夹交换数据，写入的一切内容在离开设备之前都已加密。

## 准备工作

- **S3 兼容存储**：AWS S3、Cloudflare R2、Backblaze B2、阿里云 OSS、MinIO 或其他 S3 兼容服务中的一个存储桶，以及一个可以在其中列出、读取、写入和删除对象的访问密钥。或者 **WebDAV**：Nextcloud、坚果云、群晖 NAS 或其他 WebDAV 服务中的一个文件夹，以及用户名和密码（服务提供应用专用密码时，请使用应用专用密码）。
- 以 `https://` 开头的地址。Lockra 拒绝普通的 `http://` 地址，本机地址除外。

### 按服务商填写

<StatusTag status="available" /> 自 0.7.3 版起提供。

选择存储类型后再选择服务商，Lockra 会填好地址和访问方式，除凭据外只需填写下表中的项目。列表里没有的服务，请选择「其他 S3 兼容服务」或「其他 WebDAV 服务」，按下文填写全部字段。

| 服务商             | 需要填写                                           | 说明                                                                                             |
| ------------------ | -------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| AWS S3（全球区域） | 区域、存储桶、访问密钥                             | 北京或宁夏请选「AWS S3（中国区域）」：中国区域与全球区域的账号和密钥不通用。                     |
| AWS S3（中国区域） | `cn-north-1` 或 `cn-northwest-1`、存储桶、访问密钥 | 地址以 `.amazonaws.com.cn` 结尾。                                                                |
| Cloudflare R2      | 账户 ID、存储桶、访问密钥                          | 区域为 `auto`。                                                                                  |
| 阿里云 OSS         | 地域 ID（如 `cn-hangzhou`）、存储桶、AccessKey     | 2025 年 3 月 20 日之后开通的账号，不能用默认地址访问中国内地地域的存储桶，可改用中国香港等地域。 |
| 腾讯云 COS         | 地域（如 `ap-guangzhou`）、含 APPID 的存储桶、密钥 | 存储桶名称形如 `examplebucket-1250000000`。                                                      |
| Backblaze B2       | 区域（如 `us-west-004`）、存储桶、应用密钥         | 区域是存储桶 Endpoint 的一部分。                                                                 |

| 坚果云             | 账号、应用密码                                     | 应用密码在坚果云网页「账户信息 › 安全选项 › 第三方应用管理」中生成。                             |
| Nextcloud          | 服务器地址、用户名、应用密码                       | 应用密码在「设置 › 安全」中创建。                                                                |
| 群晖 NAS           | 服务器地址、用户名、密码                           | 需要安装 WebDAV Server（HTTPS 端口默认 5006）；「文件夹」以共享文件夹开头，例如 `home/lockra`。  |

## 开始同步

1. 在第一台设备上，打开「设置 › 同步」，选择「开始同步」。
2. 选择「S3 兼容」或「WebDAV」并填写存储信息。S3 需要填写「服务地址」、「区域」（服务没有区域时填 `auto`）、「存储桶」、「访问密钥 ID」和「访问密钥」；MinIO 等自建服务请开启「路径式访问」。「文件夹（可选）」是 Lockra 在存储桶或 WebDAV 文件夹中存放文件的位置（默认为 `lockra`）。
3. 确认「这台设备的名称」，输入主密码，然后选择「开始同步」。
4. Lockra 会显示「同步密钥」：`LKS1-` 加 14 组、每组 4 个字符。请把它抄下来或存入密码管理器，并与主密码分开保管。在手边没有其他设备时添加设备，或在所有设备都丢失后恢复，都需要同步密钥和主密码两者。之后可以在「邀请其他设备」中再次查看。

存储凭据保存在加密的保险库中，不会再次显示；「设置 › 同步」只显示不含凭据的存储信息。

## 添加设备

在已开启同步的设备上，打开「设置 › 同步」，选择「邀请其他设备」并输入主密码。Lockra 会显示二维码和邀请码文本，两分钟后隐藏。邀请码包含存储凭据和同步密钥，只能在你自己的设备上使用。

在新设备上：

- **尚未创建保险库**：在欢迎页选择「加入同步…」，粘贴邀请码，输入设备名称和「同步空间的主密码」（同步空间中任一设备的主密码），然后选择「加入」。Lockra 会用这个主密码创建保险库，账号随即同步过来。
- **已有保险库**：打开「设置 › 同步 › 加入已有的同步」，输入「这台设备的主密码」。如果同步空间中的设备使用其他主密码，请同时在「同步空间的主密码（可选）」中输入其中一台设备的主密码。保险库中的账号会加入同步空间，保险库保留自己的主密码。

没有其他设备时，选择「同步密钥」而不是「邀请码」，然后填写存储信息和同步密钥。

同步空间中的每台设备都保存一份同步空间的密钥，用这台设备自己的主密码和同步密钥加密。因此，同步空间中任一设备的主密码加上同步密钥，即可添加设备。在某台设备上修改主密码后，新的主密码从这台设备的下次同步起生效；旧的主密码不再能打开同步空间，除非其他设备仍在使用它。

### 更方便的邀请与加入

<StatusTag status="available" /> 自 0.7.3 版起提供。

- **用指纹或面容显示邀请码**：开启了 Touch ID、Windows Hello 或指纹解锁的设备，在「邀请其他设备」中可以用它代替主密码。
- **可以发送的邀请码**：邀请码旁会显示一个 10 位的口令。邀请码可以通过聊天或邮件发给新设备，口令请当面或电话告诉对方；新设备粘贴邀请码后输入口令即可加入。扫描二维码不需要口令。
- **只问一次密码**：已有保险库加入时，只需输入这台设备的主密码；同步空间中的设备使用另一个主密码时，Lockra 才会请你再输入那个主密码。
- **保存同步密钥**：开始同步后，可以把同步密钥保存到你选择的文件中。在保存或选择「我已保存」之前，「设置 › 同步」会一直提醒。

## 添加手机

<StatusTag status="available" /> 自 0.7.0 版起提供。

Android 应用的同步方式与电脑相同。先在同步空间中的一台设备上显示邀请码（「设置 › 同步 › 邀请其他设备」），再在手机上选择「设置 › 同步 › 加入已有的同步 › 扫码加入」，或在新安装的欢迎页选择「从同步加入」，然后扫描邀请码。邀请码由相机直接交给 Lockra，不会显示在手机上。也可以像在电脑上一样粘贴邀请码，或输入存储设置和同步密钥。

## 用网盘文件夹同步

<StatusTag status="building" /> 正在开发，尚未发布。

在电脑上可以不填写任何存储凭据：选择一个由网盘客户端同步的文件夹，例如 OneDrive、iCloud 云盘、Dropbox、坚果云、Nextcloud、群晖 Drive 或 Syncthing 的文件夹。Lockra 只在其中写入加密的文件，由网盘客户端把它们传到其他设备。

1. 在网盘的同步文件夹中新建一个文件夹，例如 `Lockra`。
2. 在电脑上打开「设置 › 同步」，选择「开始同步」，存储类型选择「网盘文件夹」，再选择「选择文件夹…」并选中这个文件夹。
3. 确认「这台设备的名称」，输入主密码，然后选择「开始同步」。

这样的同步空间，邀请码只包含同步密钥，不包含这台电脑上的文件夹。新设备粘贴或扫描邀请码后，Lockra 会请你选择这台设备访问同一个文件夹的方式：

- **另一台电脑**：存储类型选择「网盘文件夹」，选中同一个网盘在这台电脑上的那个文件夹。
- **手机**：存储类型选择「WebDAV」，填写这个网盘的 WebDAV 地址，在「文件夹（可选）」中填写该文件夹在网盘中的路径，然后重新扫描邀请码。例如，坚果云客户端同步的 `我的坚果云/Lockra` 文件夹，对应的 WebDAV 地址是 `https://dav.jianguoyun.com/dav/`，文件夹是 `我的坚果云/Lockra`。

OneDrive、iCloud 云盘和 Dropbox 没有官方的 WebDAV，使用它们时只有电脑能加入。需要手机也同步时，请选用坚果云、Nextcloud 或群晖，或者改用 S3 兼容存储或 WebDAV。

读取本机的文件夹不需要联网：网盘客户端把其他设备的改动放进文件夹后，Lockra 约一秒后同步；此外，在前台时每 15 秒查看一次文件夹，切到其他窗口后以及同步失败后每分钟一次。其他设备的改动何时出现在这个文件夹中，取决于网盘客户端。网盘客户端未运行，或者文件夹被移动、删除时，「设置 › 同步」会提示找不到同步文件夹，Lockra 不会重新创建它；文件夹换了位置时，请在「修改存储设置」中重新选择。

0.7.3 及以前的版本不支持网盘文件夹：用这些版本打开同一个保险库文件时，账号照常可用，同步显示为关闭。

## 同步的时机

保险库解锁期间，设备会在解锁时、每次修改 3 秒后、每隔一段时间（见下文），以及你选择「立即同步」时进行同步。保险库锁定期间不会发送任何内容。状态行会显示「已同步」及时间，或上次失败的原因；下一次同步会自动重试。

### 更及时的同步

<StatusTag status="available" /> 自 0.7.3 版起提供。

- **在前台时更频繁**：Lockra 在前台时每分钟同步一次；在电脑上切到其他窗口后，每 5 分钟同步一次。在电脑上切回 Lockra 后，距上次同步满 30 秒就会同步。同步失败后，下一次在 5 分钟后进行，也可以选择「立即同步」。
- **看得到同步带来了什么**：同步新增、修改或删除了这台设备上的账号时，Lockra 会提示更改来自哪台设备，例如「已从 Pixel 8 同步：新增 2 个，修改 1 个」。

同一个账号在两台设备上都被修改时，所有设备都以较晚的修改为准。删除会在所有设备上移除该账号，除非该账号在删除之后又被修改过。「最近使用」的顺序只保存在各自的设备上。

## 设备

「设备」列出同步空间中的每台设备，以及它上次写入的时间。要移除丢失或不再使用的设备，请选择它的移除按钮：它的数据和它保存的那份密钥会从存储中删除。仍在使用的设备会在下次同步时重新出现。「重命名」会修改其他设备看到的本机名称。

## 修改存储设置或关闭同步

「修改存储设置」可以更换访问密钥、密码或地址，需要输入主密码。同步空间必须已经位于新的位置：请先移动它所在的文件夹。

「在这台设备上关闭同步」会停止本机的同步。账号保留在本机；同步空间和其他设备不受影响。之后可以用邀请码或同步密钥重新加入。

## 存储能看到什么

- **只有加密的文件。** 账号、账号的密钥、设备名称和时间在写入之前，都已在设备上用 XChaCha20-Poly1305 加密。每台设备写入一个文件，文件大小按 4 KiB 的整数倍填充，因此难以从大小准确推断账号数量。文件名只能看出设备的数量。
- **需要两个秘密才能打开同步空间。** 在每台设备上，加密这些文件的密钥本身由这台设备的主密码（经 Argon2id 派生，64 MiB 内存、3 轮）和同步密钥共同加密。没有同步密钥，即使拿到存储中的全部内容并猜中某个主密码，也无法打开；有了同步密钥，每猜一次主密码仍需完整运行一次 Argon2id。请为每台设备设置足够强的主密码。
- **设备之间不会互相覆盖。** 每台设备只写自己的文件，多台设备同时同步时会保留彼此的修改，S3 与 WebDAV 都是如此。
- **改动会被发现。** 被修改、从其他设备或同步空间移来，或被换回旧版本的文件都会被拒绝，「设置 › 同步」会指出是哪台设备。你的账号保持不变。
- **无法阻止删除。** 能写入存储的人可以删除同步空间。这会中断同步，但不会影响保险库：每台设备都保留自己的账号。
- **移除设备不会撤销其访问权限。** 被移除的设备仍保存着同步空间的密钥。要阻止丢失的设备，或知道同步密钥和旧主密码的人访问同步空间，请在所有设备上关闭同步，开始一个新的同步空间，再把设备加入其中。
- **备份不包含同步信息。** 存储设置、凭据和同步密钥只保存在保险库文件中。备份不包含这些内容；从备份恢复的设备需要重新加入同步空间。

## 出现问题时

| 提示                                                               | 处理方法                                                                                     |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 存储服务拒绝访问，请检查访问密钥或密码                             | 检查访问密钥或密码，并确认它可以在存储桶或文件夹中列出、读取、写入和删除。                   |
| 无法连接存储服务                                                   | 检查网络和地址。Lockra 会使用系统中设置的代理。                                              |
| 存储服务返回错误，请检查存储桶或文件夹是否存在                     | 检查存储桶、区域和「路径式访问」。                                                           |
| 这个存储里没有该同步密钥对应的同步空间                             | 检查地址、存储桶和「文件夹（可选）」：它们必须与其他设备上的设置相同。                       |
| 主密码或同步密钥不正确                                             | 输入同步空间中任一设备的主密码（见上文），并检查同步密钥。                                   |
| 只能通过 HTTPS 连接存储（本机地址除外）                            | 使用服务的 `https://` 地址。                                                                 |
| 某台设备的同步数据比之前读到的旧，已拒绝。存储可能被回滚           | 存储返回了这台设备较旧的文件。该设备会在下次修改时重新写入；如果提示一直存在，请移除该设备。 |
| 找不到同步文件夹：网盘客户端可能没有运行，或者文件夹已被移动或删除 | 启动网盘客户端，并确认文件夹仍在原处；文件夹换了位置时，请在「修改存储设置」中重新选择。     |
