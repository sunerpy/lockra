# 键盘快捷键

本页列出键盘快捷键。在 macOS 上，请用 ⌘ 代替本页中的 `Ctrl`。

## 应用中的任何位置

| 按键            | 操作                                                    |
| --------------- | ------------------------------------------------------- |
| `Ctrl K`        | 打开命令面板：查找账号后按 Enter 复制验证码，或执行命令 |
| `Ctrl N`        | 手动添加账号；在「密码」页添加登录项                    |
| `Ctrl G`        | 生成密码                                                |
| `Ctrl L`        | 锁定保险库                                              |
| `Ctrl ,`        | 打开设置                                                |
| `Ctrl F` 或 `/` | 跳转到验证码页的搜索框；在「密码」页时跳转到它的搜索框  |
| `Esc`           | 关闭最上层的对话框或菜单                                |

对话框打开期间，快捷键暂停生效。

## 验证码页

| 按键                 | 操作                                              |
| -------------------- | ------------------------------------------------- |
| 在搜索框中按 `↓`     | 进入列表                                          |
| 在搜索框中按 `Enter` | 复制第一个匹配项的验证码                          |
| 在搜索框中按 `Esc`   | 清除搜索                                          |
| `↑` `↓`              | 在账号之间移动（在第一个账号上按 `↑` 返回搜索框） |
| `Home` `End`         | 跳到第一个或最后一个账号                          |
| `Enter` 或 `Space`   | 复制选中账号的验证码                              |

## 密码页

<StatusTag status="available" /> 自 0.10.0 版起提供。

| 按键                 | 操作                                                            |
| -------------------- | --------------------------------------------------------------- |
| 在搜索框中按 `↓`     | 进入列表并显示第一个登录项                                      |
| 在搜索框中按 `Enter` | 显示第一个匹配的登录项                                          |
| 在搜索框中按 `Esc`   | 清除搜索                                                        |
| `↑` `↓`              | 在登录项之间移动并依次显示（在第一个登录项上按 `↑` 返回搜索框） |
| `Home` `End`         | 跳到第一个或最后一个登录项                                      |
| `Enter`              | 复制选中登录项的密码                                            |
| `Space`              | 显示选中的登录项                                                |
| 菜单键或 `Shift F10` | 打开选中登录项的菜单                                            |

## 命令面板

| 按键    | 操作                                                                                       |
| ------- | ------------------------------------------------------------------------------------------ |
| `↑` `↓` | 在结果之间移动                                                                             |
| `Enter` | 执行选中的结果：复制账号的验证码，或复制登录项的密码                                       |
| `Tab`   | 在登录项上切换到它的下一个操作（复制用户名、复制验证码、显示密码）；在其他结果上跳到下一组 |
| `Esc`   | 关闭命令面板                                                                               |

## 设置

| 按键                   | 操作                     |
| ---------------------- | ------------------------ |
| 在分组列表中按 `↑` `↓` | 在设置的各个分组之间切换 |

## 电脑上的任何位置

<StatusTag status="available" /> 自 0.10.0 版起提供。

| 按键               | 操作                                                   |
| ------------------ | ------------------------------------------------------ |
| `Ctrl Shift Space` | 设定这个快捷键后，在任何应用之上打开 Lockra 的命令面板 |

全局快捷搜索的快捷键在你于「设置 › 通用」中设定之前处于关闭状态，建议使用 `Ctrl Shift Space`；在 Wayland 上，请改为在桌面环境的键盘设置中绑定 `lockra-desktop --palette`（[全局快捷搜索](/zh/passwords/#全局快捷搜索)）。

## 浏览器中

<StatusTag status="available" /> 自 0.10.0 版起，配合[浏览器扩展](/zh/passwords/browser)使用。

| 按键                         | 操作                                              |
| ---------------------------- | ------------------------------------------------- |
| `Ctrl Shift L`               | 填充当前网站的登录项；10 秒内再按一次，填充下一个 |
| `Ctrl Shift Y`               | 打开 Lockra 弹窗                                  |
| 在输入框旁的菜单中按 `↑` `↓` | 在当前网站的登录项之间移动                        |
| 在输入框旁的菜单中按 `Enter` | 填充选中的登录项                                  |
| 在输入框旁的菜单中按 `Esc`   | 关闭菜单                                          |

前两个快捷键可以在浏览器自己的设置中修改：Chrome 为 `chrome://extensions/shortcuts`，Edge 为 `edge://extensions/shortcuts`，Firefox 为附加组件管理器中的「管理扩展快捷键」。

<StatusTag status="available" /> 自 0.16.3 版起，`Alt Shift L`（macOS 上为 `⌥ Shift L`）在当前聚焦的输入框旁打开 Lockra 菜单，任意输入框都可以，列出与当前网站匹配的登录项；同样可以在浏览器的设置中修改（[在任意输入框打开 Lockra 菜单](/zh/passwords/browser#在任意输入框打开-lockra-菜单)）。
