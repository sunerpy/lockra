# 键盘快捷键

本页列出键盘快捷键。在 macOS 上，请用 ⌘ 代替本页中的 `Ctrl`。

## 应用中的任何位置

| 按键            | 操作                                                    |
| --------------- | ------------------------------------------------------- |
| `Ctrl K`        | 打开命令面板：查找账号后按 Enter 复制验证码，或执行命令 |
| `Ctrl N`        | 手动添加账号                                            |
| `Ctrl L`        | 锁定保险库                                              |
| `Ctrl ,`        | 打开设置                                                |
| `Ctrl F` 或 `/` | 跳转到验证码页的搜索框                                  |
| `Esc`           | 关闭最上层的对话框或菜单                                |

对话框打开期间，快捷键暂停生效。

## 验证码页

| 按键                 | 操作                                              |
| -------------------- | ------------------------------------------------- |
| 在搜索框中按 `↓`     | 进入列表                                          |
| 在搜索框中按 `Enter` | 复制第一个匹配项的验证码                          |
| 在搜索框中按 `Esc`   | 清除搜索                                          |
| `↑` `↓`              | 在账号之间移动（在第一个账号上按 `↑` 返回搜索框） |
| `Home` `End`         | 跳到第一个或最后一个账号                          |
| `Enter` 或 `Space`   | 复制选中账号的验证码                              |

## 设置

| 按键                   | 操作                             |
| ---------------------- | -------------------------------- |
| 在分组列表中按 `↑` `↓` | 在通用、外观、安全和关于之间切换 |
