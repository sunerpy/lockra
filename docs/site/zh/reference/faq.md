# 常见问题与故障排除

本页回答常见问题，并说明出现问题时的处理方法。

## 忘记了主密码

主密码无法被任何人找回：保险库正是用它加密的。如果有一份用你记得的密码创建的备份，请在解锁页选择「忘记主密码？」，确认重置，然后恢复这份备份。否则，只能使用各服务提供的恢复码，在每个服务中重新设置账号。

## 服务不接受验证码

验证码取决于时间。请确认电脑的时钟设置为自动同步；时钟偏差一分钟，生成的验证码就会被服务拒绝。如果只有一个账号出现问题，请在「编辑…」和导入预览中，将它的设置（位数、周期、算法）与服务设置页面上的说明进行对比。

## 无法截取 Google 身份验证器的导出页面

Android 版应用禁止截取导出二维码。请用另一部手机或相机拍摄屏幕，再导入照片；清晰、正对屏幕的照片最容易读取。在 iPhone 上可以直接截图。

## 预览提示缺少 Google 导出中的某张二维码

导出的账号较多时会分成几张二维码，并在手机上编号。请导入所有二维码的图片；预览会统计已读取的数量，并指出缺少哪几张。

## Microsoft Authenticator 的账号被列为不支持

工作或学校账户不在手机上保存其他应用可用的密钥；较新版本的应用也可能对其他账号的密钥进行加密。请在对应服务中以 Lockra 作为验证器重新设置这些账号。

## 「在本机记住」显示为灰色

没有可用的系统钥匙串。在 Linux 上，请安装并启动支持 Secret Service 的钥匙串，例如 GNOME 钥匙圈或 KWallet，然后重新启动 Lockra。

## 自动备份失败

备份页会显示错误及其发生时间。通常是因为文件夹所在的磁盘未连接，或者 Lockra 已无权写入该文件夹。请重新连接磁盘或选择其他文件夹；下次修改或选择「立即自动备份」时会写入新的备份。

## Lockra 能否离线使用？

始终可以：Lockra 从不联网。验证码根据每个账号的密钥和当前时间在电脑上计算。

## 账号保存在哪里？

保存在电脑上的一个加密文件中。详见[隐私](/zh/privacy)和[更新、卸载与数据](/zh/guide/updates#文件位置)。
