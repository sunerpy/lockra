# 快速开始

本页带你从全新安装开始，在几分钟内复制第一个验证码。

## 创建保险库

Lockra 首次启动时会要求设置主密码。主密码用于加密全部账号，**无法找回**：一旦忘记，任何人都无法打开保险库，用这个主密码创建的备份也无法打开。请选择一句只有你知道、并且能准确输入的话，至少 8 个字符，输入两遍。输入框下方的强度条可供参考。

如果你已经有 Lockra 备份，请改为选择「从备份恢复」：备份的密码将成为主密码。

## 导入账号

在侧栏中打开「导入」，选择来源：

- **Google 身份验证器**：在手机上导出账号，用另一台设备拍下二维码，再把照片拖到窗口中。详见 [Google 身份验证器](/zh/transfer/google)。
- **Microsoft Authenticator**：详见 [Microsoft Authenticator](/zh/transfer/microsoft)；需要已 root 的 Android 手机。
- **网站的设置页面**：网站显示用于设置验证器的二维码时，截取它，或复制它的 otpauth 链接，然后选择「从剪贴板导入」。

Lockra 会先列出找到的内容，然后才保存。核对列表后选择「导入」。

也可以手动添加单个账号：在验证码页选择「添加 › 手动输入…」，或按 `Ctrl N`。

## 复制验证码

「验证码」页列出各个账号的当前验证码，旁边的圆环表示剩余时间。点击账号即可复制验证码，然后粘贴到网站中。30 秒后，如果剪贴板中仍是这个验证码，Lockra 会将其清空。

按 `Ctrl K` 打开命令面板：输入账号名称的一部分后按 Enter，无需使用鼠标即可复制验证码。

## 开启自动备份

打开「备份」，开启「自动备份」并选择一个文件夹，最好是由云盘同步的文件夹。此后每次修改几秒后，都会在那里写入一份加密备份。详见[备份与恢复](/zh/backup/)。

## 离开时锁定

Lockra 在无操作 5 分钟后自动锁定。按 `Ctrl L` 可以立即锁定，输入主密码即可再次解锁。
