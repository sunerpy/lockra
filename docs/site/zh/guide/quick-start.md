# 快速开始

本页带你从全新安装开始，在几分钟内复制第一个验证码。

## 创建保险库

Lockra 首次启动时会要求设置主密码。主密码用于加密全部账号，**无法找回**：一旦忘记，任何人都无法打开保险库，用这个主密码创建的备份也无法打开。请选择一句只有你知道、并且能准确输入的话，至少 8 个字符，输入两遍。输入框下方的强度条可供参考。

如果你已经有 Lockra 备份，请改为选择「从备份恢复」：备份的密码将成为主密码。

## 导入账号

在侧栏中打开「导入」，选择来源：

- **Google 身份验证器**：在手机上导出账号，用另一台设备拍下二维码，再把照片拖到窗口中。详见 [Google 身份验证器](/zh/transfer/google)。
- **Microsoft Authenticator**：详见 [Microsoft Authenticator](/zh/transfer/microsoft)；需要已 root 的 Android 手机。
- **网站的设置页面**：网站显示用于设置验证器的二维码时，截取它，或复制它的 otpauth 链接，然后选择「从剪贴板导入」。

Lockra 会先列出找到的内容，然后才保存。核对列表后选择「导入」。浏览器或密码管理器中的密码也以同样的方式导入（[导入与导出登录项](/zh/passwords/import-export)）。

也可以手动添加单个账号：在验证码页选择「添加 › 手动输入…」，或按 `Ctrl N`。

## 复制验证码

「验证码」页列出各个账号的当前验证码，旁边的圆环表示剩余时间。点击账号即可复制验证码，然后粘贴到网站中。30 秒后，如果剪贴板中仍是这个验证码，Lockra 会将其清空。

按 `Ctrl K` 打开命令面板：输入账号名称的一部分后按 Enter，无需使用鼠标即可复制验证码。

## 开启自动备份

打开「备份」，开启「自动备份」并选择一个文件夹，最好是由云盘同步的文件夹。此后每次修改几秒后，都会在那里写入一份加密备份。详见[备份与恢复](/zh/backup/)。

## 离开时锁定

Lockra 在无操作 5 分钟后自动锁定。按 `Ctrl L` 可以立即锁定，输入主密码即可再次解锁。

## 托盘图标

<StatusTag status="available" /> 自 0.10.0 版起提供。

Lockra 在电脑上运行时，托盘中有它的挂锁图标：Windows 上位于通知区域，macOS 上位于菜单栏。点击图标即可打开窗口；右键点击会打开菜单，包括「打开 Lockra」「快捷搜索」「锁定」「设置…」「检查更新…」和「退出 Lockra」。在 Linux 上，点击图标会直接打开这个菜单。「检查更新…」会打开软件更新对话框，没有正在进行的更新时会立即检查一次。Lockra 锁定时，「锁定」「设置…」和「检查更新…」不可用。

关闭窗口即退出 Lockra；开启「设置 › 浏览器 › 关闭窗口后继续运行」后，关闭窗口只会隐藏窗口，Lockra 继续留在托盘中运行。

## 登录时启动

<StatusTag status="available" /> 自 0.13.0 版起，「设置 › 通用 › 登录时启动 Lockra」会在你登录电脑后自动运行 Lockra，浏览器扩展和快捷搜索随时可用。它用的是系统自带的启动项，只对当前用户生效：Windows 上是 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的一项（任务管理器的「启动应用」中能看到）；macOS 上是 `~/Library/LaunchAgents` 中的一个 LaunchAgent（「系统设置 › 通用 › 登录项」中会列出）；Linux 上是 `~/.config/autostart` 中的自动启动项。在任务管理器或桌面环境的「启动应用程序」中关闭后，这个开关也显示为关闭；在 macOS 的「登录项」中关闭后，Lockra 不再自动运行，但这个开关仍显示为开启。开启「设置 › 浏览器 › 关闭窗口后继续运行」时，登录后 Lockra 只在托盘中运行，不打开窗口；未开启时会打开窗口。每次启动时，Lockra 都会重写已开启的启动项，程序位置改变后（例如移动了 AppImage）它仍然有效。
