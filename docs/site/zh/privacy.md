# 隐私

本页列出 Lockra 保存哪些内容、保存在哪里，以及发送哪些内容：检查和下载更新，以及从 0.4.0 版起开启同步后写入你自己存储的加密文件。

## Lockra 保存的内容

| 内容                                 | 位置                                | 方式           |
| ------------------------------------ | ----------------------------------- | -------------- |
| 你的账号                             | Lockra 数据目录中的 `vault.lockra`  | 使用主密码加密 |
| 设置（主题、语言、计时、备份文件夹） | Lockra 设置目录中的 `settings.json` | 明文，不含机密 |
| 「在本机记住」的密钥（如已开启）     | 系统钥匙串                          | 受系统登录保护 |
| 备份                                 | 你保存的位置，以及自动备份文件夹    | 加密           |
| 同步设置与凭据（如已开启同步）       | `vault.lockra` 中                   | 使用主密码加密 |
| 同步空间（如已开启同步）             | 你设置的存储桶或 WebDAV 文件夹      | 在设备上加密   |

[更新、卸载与数据](/zh/guide/updates#文件位置)列出了各个系统上的目录。

## Lockra 发送的内容

检查和下载更新，以及你开启的同步。当你选择「检查更新」时，Lockra 会向 GitHub 查询最新版本，并在你选择「立即更新」时下载安装包。开启「设置 › 通用 › 自动更新」后，Lockra 还会在每次启动 10 秒后查询，并在后台下载新版本。这些请求不包含账号、保险库或设置中的任何内容；与任何下载一样，GitHub 能看到请求及其来源地址（[更新](/zh/guide/updates#更新)）。

开启同步后（0.4.0 版起），每台设备把加密文件写入你设置的 S3 兼容存储桶或 WebDAV 文件夹，并从那里读取其他设备的文件，同步不会连接其他任何地方。存储能看到加密的文件、按 4 KiB 取整的文件大小、设备的数量以及它们写入的时间，但看不到任何账号、密钥或设备名称（[多设备同步](/zh/backup/sync)）。

Lockra 没有用户账户、没有服务器，也没有崩溃报告或遥测。字体、图片和图标都随应用提供。只有在你导出账号、把备份保存到会同步的位置，或通过你的存储加密同步时，账号才会离开设备。

## 在 Android 上

<StatusTag status="available" /> 自 0.7.0 版起提供。

Android 应用把保险库和设置保存在应用的私有目录中，Android 自带的备份和设备迁移不包含这个目录；「使用指纹解锁」的密钥保存在手机的安全硬件中。它发送的内容与电脑相同，只有一点不同：只在你点按「检查更新」时才检查更新，并且自身不下载任何内容，新版本的发布页会在浏览器中打开。

## 剪贴板与屏幕

复制的验证码进入系统剪贴板，在 Lockra 清空剪贴板之前，其他应用可以读取。密钥和导出二维码只在输入主密码后才会显示在屏幕上，详见 [Lockra 如何保护你的账号](/zh/security/)。
