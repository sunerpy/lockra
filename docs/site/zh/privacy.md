# 隐私

本页列出 Lockra 保存哪些内容、保存在哪里，以及发送哪些内容：除检查更新外，不发送任何内容。

## Lockra 保存的内容

| 内容                                 | 位置                                | 方式           |
| ------------------------------------ | ----------------------------------- | -------------- |
| 你的账号                             | Lockra 数据目录中的 `vault.lockra`  | 使用主密码加密 |
| 设置（主题、语言、计时、备份文件夹） | Lockra 设置目录中的 `settings.json` | 明文，不含机密 |
| 「在本机记住」的密钥（如已开启）     | 系统钥匙串                          | 受系统登录保护 |
| 备份                                 | 你保存的位置，以及自动备份文件夹    | 加密           |

[更新、卸载与数据](/zh/guide/updates#文件位置)列出了各个系统上的目录。

## Lockra 发送的内容

只有检查更新。当你选择「设置 › 关于 › 检查更新」，或开启自动检查后每天一次，Lockra 会向 GitHub 查询最新版本，并在你选择安装时下载安装包。这些请求不包含账号、保险库或设置中的任何内容；与任何下载一样，GitHub 能看到请求及其来源地址（[更新](/zh/guide/updates#更新)）。没有账户、同步、崩溃报告或遥测。字体、图片和图标都随应用提供。只有在你导出账号，或把备份保存到会同步的位置时，账号才会离开这台电脑。

## 剪贴板与屏幕

复制的验证码进入系统剪贴板，在 Lockra 清空剪贴板之前，其他应用可以读取。密钥和导出二维码只在输入主密码后才会显示在屏幕上，详见 [Lockra 如何保护你的账号](/zh/security/)。
