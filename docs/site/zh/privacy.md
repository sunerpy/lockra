# 隐私

本页列出 Lockra 保存哪些内容、保存在哪里，以及发送哪些内容：检查和下载更新，以及开启同步后写入你自己存储（0.4.0 版起）或 Lockra 中继（0.8.1 版起）的加密文件。

## Lockra 保存的内容

| 内容                                 | 位置                                | 方式           |
| ------------------------------------ | ----------------------------------- | -------------- |
| 你的账号                             | Lockra 数据目录中的 `vault.lockra`  | 使用主密码加密 |
| 设置（主题、语言、计时、备份文件夹） | Lockra 设置目录中的 `settings.json` | 明文，不含机密 |
| 「在本机记住」的密钥（如已开启）     | 系统钥匙串                          | 受系统登录保护 |
| 备份                                 | 你保存的位置，以及自动备份文件夹    | 加密           |
| 同步设置与凭据（如已开启同步）       | `vault.lockra` 中                   | 使用主密码加密 |
| 同步空间（如已开启同步）             | 你设置的中继、存储桶或文件夹        | 在设备上加密   |

[更新、卸载与数据](/zh/guide/updates#文件位置)列出了各个系统上的目录。

## Lockra 发送的内容

检查和下载更新，以及你开启的同步。当你选择「检查更新」时，Lockra 会向 GitHub 查询最新版本，并在你选择「立即更新」时下载安装包。开启「设置 › 通用 › 自动更新」后，Lockra 还会在每次启动 10 秒后查询，并在后台下载新版本。这些请求不包含账号、保险库或设置中的任何内容；与任何下载一样，GitHub 能看到请求及其来源地址（[更新](/zh/guide/updates#更新)）。

开启同步后（0.4.0 版起），每台设备把加密文件写入你设置的 S3 兼容存储桶或 WebDAV 文件夹，并从那里读取其他设备的文件，同步不会连接其他任何地方。存储能看到加密的文件、按 4 KiB 取整的文件大小、设备的数量以及它们写入的时间，但看不到任何账号、密钥或设备名称（[多设备同步](/zh/backup/sync)）。

使用 Lockra 中继时（0.8.1 版起），设备改为在中继上写入和读取同样的加密文件；内置中继收到和保存的内容见下文。

Lockra 没有用户账户，也没有崩溃报告或遥测。字体、图片和图标都随应用提供。只有在你导出账号、把备份保存到会同步的位置，或通过你的存储或中继加密同步时，账号才会离开设备。

## 内置中继

<StatusTag status="available" /> 自 0.8.1 版起提供。

同步时选择「Lockra 内置中继」后，每台设备会把加密文件发送到 Lockra 运行的中继，并从那里读取其他设备的文件。中继由 Lockra 的开发者运行，服务器位于 AWS 首尔区域（韩国）。

- **中继收到的内容**：设备生成的加密文件；由同步空间的密钥计算出的同步空间标识和每台设备的标识，无法据此在其他同步空间中认出同一台设备；设备用来证明身份的值，中继只保存它的指纹；以及每个请求的来源网络地址。
- **中继看不到的内容**：你的账号、账号的密钥、设备名称、恢复密钥和主密码。文件在中继上始终保持加密，中继和 Lockra 的开发者都无法打开。
- **保存期限**：设备最后一次访问同步空间 400 天后，同步空间及其文件会被删除。在「设置 › 同步」中移除设备时，它的文件会立即删除。
- **网络地址**：只保存在中继的内存中，用于限制每个地址的请求次数，从不写入磁盘。中继不记录请求，它前端的负载均衡器也不保存访问日志。
- **不共享**：中继保存的任何内容都不会共享或出售。服务器由 AWS 托管。

## 在 Android 上

<StatusTag status="available" /> 自 0.7.0 版起提供。

Android 应用把保险库和设置保存在应用的私有目录中，Android 自带的备份和设备迁移不包含这个目录；「使用指纹解锁」的密钥保存在手机的安全硬件中。它发送的内容与电脑相同，只有一点不同：只在你点按「检查更新」时才检查更新，并且自身不下载任何内容，新版本的发布页会在浏览器中打开。

## 剪贴板与屏幕

复制的验证码进入系统剪贴板，在 Lockra 清空剪贴板之前，其他应用可以读取。密钥和导出二维码只在输入主密码（或在手机上通过指纹验证）后才会显示在屏幕上，详见 [Lockra 如何保护你的账号](/zh/security/)。
