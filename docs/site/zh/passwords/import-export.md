# 导入与导出登录项

本页介绍如何把浏览器或其他密码管理器中的登录项导入 Lockra，以及如何导出登录项供其他应用使用。

<StatusTag status="available" /> 自 0.10.0 版起提供。

## Lockra 能读取的文件

请先在其他应用中导出密码，再导入它写出的文件：

| 应用                 | 文件                                        |
| -------------------- | ------------------------------------------- |
| Chrome、Edge         | 浏览器导出密码时生成的 CSV 文件             |
| Firefox              | 它导出密码时生成的 CSV 文件                 |
| Safari、「密码」应用 | 它导出密码时生成的 CSV 文件，包含验证码     |
| Bitwarden            | CSV 导出文件，或未加密的 JSON 导出文件      |
| 1Password            | 1PUX 导出文件，或 CSV 导出文件              |
| LastPass             | CSV 导出文件                                |
| KeePass、KeePassXC   | KDBX 4 数据库，以及它的密码、密钥文件或两者 |

Lockra 根据文件的内容识别文件类型，与文件名无关。加密的 Bitwarden 导出文件会被列为不支持，并建议改为导出未加密的 JSON；KDBX 4 之前的 KeePass 数据库无法读取。

## 导入

在电脑上，打开「导入」，在「浏览器和密码管理器」下选择「选择导出文件…」，也可以把文件拖到窗口中；「密码」页的「添加登录项 › 从其他应用导入…」也会来到这里。在手机上，选择「添加 › 从文件导入」。确认预览之前，不会保存任何内容。

KeePass 数据库会先要求输入它的密码（「…」需要 KeePass 数据库的密码）。「选择密钥文件…」可以添加它的密钥文件；数据库只用密钥文件保护时，密码留空。然后选择「打开数据库」。密码错误时会提示「密码错误」；使用密钥文件时，会提示「密钥文件无效，或与密码不匹配」。

### 导入预览

预览列出找到的每个登录项和每个验证码，并标明类型（「登录项」或「验证码」），登录项还会注明是否带有验证码。每个登录项都按网站、用户名和密码与保险库中的登录项比较：

| 状态           | 条件                                                                       | 默认操作                               |
| -------------- | -------------------------------------------------------------------------- | -------------------------------------- |
| **新增**       | 保险库中没有类似的登录项                                                   | 添加                                   |
| **已存在**     | 保险库中有网站、用户名和密码都相同的登录项，且验证码相同或文件中没有验证码 | 跳过                                   |
| **重复**       | 同一个文件中较早的一个登录项与它相同                                       | 跳过                                   |
| **与本机不同** | 保险库中有网站和用户名相同、但密码或验证码不同的登录项                     | 替换；被替换的密码进入登录项的密码历史 |

可以为每一项选择「添加」「跳过」或「替换现有」；「添加」会同时保留两个登录项。验证码按账号的规则比较（[已在保险库中的账号](/zh/accounts/add#已在保险库中的账号)）。

### 导入的内容

- 标题、用户名、密码、备注和网址；除非导出文件另有说明，每个网址都按注册域匹配（保留 Bitwarden 自己的匹配方式）。
- 文件夹、集合或 KeePass 群组成为登录项的分组（嵌套的分组以路径表示，例如 `Work/Servers`），以及收藏、标签和自定义字段，隐藏的字段仍然隐藏。
- 在 Bitwarden 中设置为使用前重新输入主密码的条目，导入后保护级别为「填充前验证」（[保护级别](/zh/passwords/#保护级别)）。
- 登录项的验证码成为验证码页上的一个账号，并与登录项关联。保险库中已有密钥相同的账号时，登录项改为关联那个账号。

详情栏的「来源」会注明登录项来自哪个应用。银行卡、身份信息、安全笔记和其他类型的条目会被列为不支持并说明原因；超出 Lockra 上限的登录项（单个值超过 4 KiB、备注超过 64 KiB 或字段超过 64 个）也是如此。KeePass 回收站中的条目不会导入。

除 KeePass 数据库外，导入的文件以明文保存所有密码：导入完成后，请删除这个文件。

## 导出

打开「导出」（在手机上为「设置 › 导出」），在「导出内容」中选择「登录项」。「选择登录项」中的所有登录项默认都已勾选，取消勾选即可排除。然后在「导出为」中选择：

- **KeePass 数据库**：KDBX 4 格式的加密文件，KeePassXC、KeePass、Strongbox 等应用都能打开。在「数据库密码」和「再输入一次」中设置它的密码，至少 8 个字符。验证码保存在每个条目的 `otp` 字段中。
- **明文 CSV 文件**：Bitwarden 格式的表格，大多数密码管理器都能导入。这个文件**没有加密**：任何拿到它的人都能看到其中的全部密码。只有在你开启「我知道这个文件不加密，任何人都能读到其中的密码」之后，Lockra 才会保存它。

输入主密码（手机上开启了指纹解锁时，主密码留空即可用指纹验证），然后选择「保存数据库…」或「保存 CSV 文件…」，再选择文件的保存位置。在 Linux 和 macOS 上，只有你的用户账户可以读取这个文件。其他应用导入完成后，请删除 CSV 文件。

不会导出的内容：每个网址的匹配方式（再次导入时按注册域匹配）、密码历史、时间、颜色和自动填充设置；KeePass 数据库还不包含收藏和「填充前验证」，CSV 文件不包含标签。由更新版本的 Lockra 写入的登录项不会导出。

如果是为了妥善保存登录项而不是迁移，请使用[备份](/zh/backup/)：备份同样包含登录项，并且经过加密。
