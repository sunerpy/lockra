# 添加账号

本页介绍如何添加单个账号，可以从服务的设置页面添加，也可以手动输入。要一次迁移多个账号，请参阅[迁移账号](/zh/transfer/google)。

## 通过二维码或链接添加

服务在开启两步验证时会显示一个二维码，通常还在下方提供链接或密钥。

- **二维码**：截取二维码，然后在验证码页选择「添加 › 从剪贴板导入」。Lockra 会从图片中读取二维码。
- **链接**（`otpauth://…`）：复制链接，然后选择「添加 › 粘贴 otpauth 链接…」或「从剪贴板导入」。

无论哪种方式，服务随后都会要求输入当前验证码以完成确认：从 Lockra 中复制即可。

## 手动输入

有些服务只提供密钥，例如 `JBSW Y3DP EHPK 3PXP`。选择「添加 › 手动输入…」（`Ctrl N`），输入服务名称和账号，再粘贴密钥；空格和大小写不影响结果。

大多数服务使用默认设置：基于时间、6 位、30 秒周期、SHA1。服务另有说明时，请打开「高级设置」并选择：

| 设置   | 可选值                               |
| ------ | ------------------------------------ |
| 类型   | 基于时间（TOTP）或基于计数器（HOTP） |
| 周期   | 1 至 3600 秒（TOTP）                 |
| 计数器 | 起始值（HOTP）                       |
| 位数   | 6、7 或 8                            |
| 算法   | SHA1、SHA256 或 SHA512               |

## 在 Android 上

<StatusTag status="available" /> 自 0.7.0 版起提供。

在手机上，「添加」提供「扫描二维码」（使用相机）、「从照片中读取」（含二维码的截图或照片）、「从文件导入」、「粘贴链接」、「从剪贴板导入」和「手动添加账号」。首次使用相机时会请求相机权限，读到的内容直接进入导入预览。相机打开期间离开应用，保险库会锁定。

## 已在保险库中的账号

如果添加的账号与保险库中某个账号的密钥相同，添加会被拒绝，因此同一个账号不会出现两次。服务名称和账号相同、但密钥不同的账号会与现有账号并列添加：重新设置验证器时，服务会签发新的密钥。
