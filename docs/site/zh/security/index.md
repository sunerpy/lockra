# Lockra 如何保护你的账号

本页介绍 Lockra 如何保护你的账号、每项安全设置的作用，以及它无法防范的情况。

## 主密码

所有账号保存在一个文件中，使用由主密码派生的密钥加密：Argon2id 使用 64 MiB 内存、3 轮迭代完成派生，因此逐个尝试密码的速度很慢。文件使用 XChaCha20-Poly1305 加密；只要其中任何部分被改动，哪怕只有 1 个字节，Lockra 都会拒绝打开，而不会读取被篡改的数据。

连续输错 3 次密码后，每次再尝试都需要等待，等待时间从 1 秒开始，每次加倍，最长 30 秒。

主密码无法找回。如果遗失了主密码，可以在解锁页选择「忘记主密码？」，并输入「重置」以确认，重置保险库：Lockra 会从一个空的保险库重新开始，旧文件改名后保留，没有它的密码仍然无法打开。

要修改主密码，请打开「设置 › 安全 › 修改主密码」。之前的备份仍然使用旧密码打开。

## 在本机记住

「设置 › 安全 › 在本机记住」会把一个密钥保存在系统钥匙串中（Windows 上为凭据管理器，macOS 上为钥匙串，Linux 上为 Secret Service），在这台电脑上解锁保险库时无需输入主密码。此后，任何能登录你这台电脑账户的人都能打开保险库，因此请只在仅供你本人使用的电脑上开启。

关闭这项设置时需要输入主密码。Lockra 会从钥匙串中删除密钥，并重新加密保险库，因此被删除的密钥此后无法打开任何内容。

## Touch ID 与 Windows Hello

<StatusTag status="available" /> 自 0.5.0 版起提供。

在带 Touch ID 的 Mac 或支持 Windows Hello 的 Windows 电脑上，开启「设置 › 安全 › 使用 Touch ID 解锁」（Windows 上为「使用 Windows Hello 解锁」）。开启时会验证一次，确认可以使用，并同时开启「在本机记住」。解锁页随即显示「使用 Touch ID 解锁」（或「使用 Windows Hello 解锁」）：先验证你的指纹，或 Windows Hello 的指纹、面容或 PIN，再用本机记住的密钥打开保险库。尚未开启时，支持 Touch ID 或 Windows Hello 的电脑会在解锁页提示开关的位置。关闭时需要输入主密码，「在本机记住」会保持开启。主密码始终可以解锁。

在 Windows 上，如果解锁的那一刻 Windows Hello 恰好不可用（例如另一个应用正在显示 Windows Hello 窗口），Windows 会改为要求输入你的 Windows 登录密码。

这项验证防范的是有人使用你已登录的电脑。以你的身份运行的程序仍然可以从钥匙串中读取本机记住的密钥，与不开启验证时相同。

## 默认解锁方式

<StatusTag status="available" /> 自 0.7.0 版起提供。

开启「使用 Touch ID 解锁」（或「使用 Windows Hello 解锁」）后，「设置 › 安全 › 默认解锁方式」决定解锁页先做什么。选择「Touch ID」（Windows 上为「Windows Hello」，默认选项）时，验证按钮排在最前，解锁页会自动请求验证：Lockra 启动时、窗口在前台时自动锁定时，以及在锁定状态下切回 Lockra 窗口时。你自己锁定或取消验证后，离开窗口再回来时才会再次请求。Lockra 在后台时不会请求。选择「主密码」时，先输入主密码，验证需要点按钮。

## Android 上的指纹解锁

<StatusTag status="available" /> 自 0.7.0 版起提供。

在手机上，「设置 › 安全 › 使用指纹解锁」把保险库的密钥保存在手机的安全硬件中，只在指纹验证通过后的十秒内可以使用。开启时会验证一次；关闭时需要输入主密码，密钥随之删除。之后录入新的指纹会使这个密钥失效，此时使用主密码解锁，并可以重新开启这项设置。「默认解锁方式」为「指纹」时，打开或切回 Lockra 会自动请求指纹验证。在手机上，Lockra 始终无法被截屏，离开应用时保险库会锁定。

### 默认开启指纹解锁

<StatusTag status="available" /> 自 0.7.1 版起提供。

在录有指纹的手机上，新建保险库、从备份恢复或从同步加入时，欢迎页的「使用指纹解锁」默认打开：保险库打开后验证一次指纹即开启。关闭这个开关则不开启，之后也不再询问。已有的保险库用主密码解锁后，Lockra 会询问一次是否开启指纹解锁；选择「暂不」后，这部手机不再询问，仍可以在「设置 › 安全」中开启。

## 锁定

在没有按键或点击的情况下，Lockra 默认在 5 分钟后锁定（「设置 › 安全 › 自动锁定」：1 至 60 分钟，或从不）；按 `Ctrl L` 或选择侧栏中的「锁定」会立即锁定。锁定会从内存中清除已解密的账号，并关闭正在进行的导入或导出。

## 剪贴板

复制的验证码会在 30 秒后从剪贴板中清除（「设置 › 安全 › 清空剪贴板」：10 至 90 秒，或从不），且只在剪贴板中仍是这个验证码时清除。在 Windows 上，验证码不会进入剪贴板历史、云剪贴板，也不会被剪贴板监视程序读取；在 macOS 和 Linux 上，验证码会被标记为不进入剪贴板历史，支持这个标记的剪贴板管理器会遵守它。

## 屏幕上的密钥

显示账号的密钥（「显示密钥…」）和显示导出二维码都需要再次输入主密码，并会在 2 分钟后隐藏。显示期间，Windows 和 macOS 会把窗口排除在截屏和录屏之外。Linux 没有这样的控制手段：显示页面会说明这一点，请注意屏幕共享。

「设置 › 安全 › 隐藏验证码」会以圆点代替验证码，鼠标指向某个账号时才显示。

## 同步

同步（0.4.0 版起）默认关闭，需要在你自己的存储上开启。设备写入存储的一切内容都在设备上加密，加密它们的密钥只有同时具备同步空间中某台设备的主密码和同步密钥才能打开。每台设备只写自己的文件，设备之间不会覆盖彼此的修改；被修改或换回旧版本的文件会被拒绝。存储凭据和同步密钥保存在加密的保险库中，不会出现在备份里。[多设备同步](/zh/backup/sync#存储能看到什么)说明了存储能看到哪些内容。

## Lockra 无法防范的情况

- 以你的用户身份在电脑上运行的恶意软件可以读取你输入的内容，包括主密码。
- 开启「在本机记住」后，保险库的安全程度与你在这台电脑上的账户相同。
- 遗忘的主密码无法被任何人找回。
- 开启同步后，同时拿到存储内容和同步密钥的人（例如拍下了邀请码）可以在自己的电脑上逐一尝试各台设备的主密码；为每台设备设置足够长的主密码是唯一的防线。能写入存储的人可以删除同步空间，这会中断同步，但不会影响你的保险库。移除设备不会撤销其访问权限。
